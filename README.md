# Image Steganography Using LSB and RC6

## 📌 Project Overview

Image Steganography Using LSB and RC6 is a Python-based
application designed to hide secret messages within
digital images and retrieve them when required.

The project combines the Least Significant Bit (LSB)
technique for image steganography with RC6 encryption
to provide an additional layer of security for secret
messages.

## 🎯 Objectives

- To hide secret messages within digital images.
- To extract hidden messages from encoded images.
- To protect message contents using RC6 encryption.
- To develop a simple and user-friendly application.

## ✨ Key Features

- Hide secret messages inside images using LSB.
- Extract hidden messages from encoded images.
- Encrypt and decrypt messages using RC6.
- Image-based data hiding.
- User-friendly graphical interface.

## 🛠️ Technologies Used

- Python
- Least Significant Bit (LSB) Steganography
- RC6 Encryption
- OpenCV
- CustomTkinter

## ⚙️ How It Works

1. Select an image.
2. Enter the secret message.
3. Encrypt the message using RC6.
4. Embed the message into the image using LSB.
5. Save the encoded image.
6. Select the encoded image to retrieve the message.
7. Decrypt the extracted message to obtain the original text.
