# 🔐 Image Steganography Using LSB and RC6

### Secure Message Hiding Using Python

## 📌 Project Overview

Image Steganography Using LSB and RC6 is a Python-based application developed to hide secret messages within digital images and retrieve them when required.

This project combines the Least Significant Bit (LSB) steganography technique with cryptographic algorithms to improve the security and confidentiality of secret messages.

The application provides a graphical user interface that allows users to perform message hiding and extraction operations.

## 🎯 Objectives

- To hide secret messages inside digital images.
- To extract hidden messages from encoded images.
- To implement LSB-based image steganography.
- To apply encryption techniques for message security.
- To develop a user-friendly Python application.

## ✨ Features

-  Hide secret messages inside images.
-  Extract hidden messages from encoded images.
-  Protect message confidentiality using encryption.
-  User-friendly graphical interface.
-  Python-based implementation.
-  Project documentation included.

## 🛠️ Technologies Used

- Python
- Least Significant Bit (LSB) Steganography
- RC6 Encryption
- AES and RSA Encryption 
- OpenCV 
- CustomTkinter

## ⚙️ How It Works

1. Select an image to use as the cover image.
2. Enter the secret message.
3. Encrypt the message using the implemented encryption algorithm.
4. Embed the message into the image using LSB steganography.
5. Save the encoded image.
6. Select the encoded image to extract the hidden data.
7. Decrypt the extracted data to recover the original message.
